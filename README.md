# 📱 Boutique en ligne — E-Commerce Mobile

Application web e-commerce complète dédiée à la vente de téléphones mobiles en ligne. Ce projet met en pratique l'architecture Full Stack, de la conception de l'interface utilisateur jusqu'à la gestion de la base de données.

## ✨ Fonctionnalités principales
* **Catalogue de produits :** Affichage dynamique des smartphones avec détails et tarifs.
* **Gestion du panier :** Ajout, suppression et calcul automatique du montant total des commandes.
* **Espace utilisateur :** Inscription, connexion sécurisée et suivi des achats.
* **Interface responsive :** Navigation fluide adaptée aux ordinateurs, tablettes et mobiles.

## 🛠️ Technologies utilisées
* **Frontend :** HTML5, CSS3, Bootstrap 5
* **Backend :** PHP
* **Base de données :** MySQL / SQL
